# ⚡ Electric3D v0.3 — C++ Circuit & PCB Studio (Windows)

Эта версия **полностью переписана на C++17**. Интерфейс — нативный Win32/GDI, 3D-плата отображается изометрической 3D-проекцией с поворотом камеры. Python и внешние графические библиотеки **не нужны**. Исходники в репозитории собираются с помощью CMake и компилятора MSVC на GitHub Actions.

## Что работает

- **Создание печатной платы (PCB)**: новый проект, изменение размеров платы (6–60 единиц), зелёная 3D-плата с сеткой, расстановка компонентов с шагом 0,5, вращение деталей по 90°, поворот/масштаб камеры, провода между конкретными контактами, сохранение `.elctrd`.
- **21 тип компонента**: батарейка, резистор, светодиод, лампа, переключатель, конденсатор, диод, мотор, зуммер, предохранитель, амперметр, вольтметр, NPN, PNP, N-MOSFET, кнопка, потенциометр, фоторезистор, реле, разъём и **программируемый C++-контроллер**.
- **Контакты транзисторов**: у NPN/PNP — B (base), C (collector), E (emitter); у N-MOSFET — G (gate), D (drain), S (source).
- **Подключение контроллера**: VCC и GND — питание, D0..D3 — четыре программируемых цифровых контакта. Подключите D0 к затвору MOSFET (G), чтобы переключать ток через светодиод/лампу.
- **Программирование на C++ прямо в окне программы**: редактируйте `controller_tick`, нажимайте `Compile + Load C++`. Программа компилирует вашу прошивку в локальную DLL с помощью **установленного на ПК g++ (MinGW-w64) или cl.exe (MSVC Developer Prompt)** и загружает её для симуляции. Без установленного компилятора доступна **встроенная мигающая демонстрация**, но изменённый текст C++ не исполняется до компиляции.
- **Приближённый расчёт постоянного тока**: соединения как электрические узлы, резистивные элементы, батарейки с внутренним сопротивлением, идеализированные диоды и управляемое состояние транзисторов/реле. Подсветка активных LED/ламп/проводов, оценка тока в инспекторе.
- **Открытие старых `.elctrd` v1 и v2**, сохранение в `.elctrd` v3 с размерами PCB и текстом C++ прошивки.

## Запуск и действия в программе

1. На левой панели выберите компонент. Нажмите **Place part** и нажмите на 3D-плату.
2. Нажмите **Connect pins** и щёлкните два жёлтых контакта на разных деталях. Для нескольких проводов в одной точке повторите соединение.
3. Нажмите **Select / Move** для выделения и перетаскивания, **Rotate 90 deg** для поворота, **Erase wire** для удаления провода.
4. Справа измените **PCB size**. Для программирования выберите **C++ controller**; подключите к батарее VCC/GND, затем цифровой D0 к транзистору.
5. Исправьте код C++ в правом редакторе и нажмите **Compile + Load C++** (установленный компилятор обязателен). Нажмите **Save** для сохранения `.elctrd` вместе с программой.
6. Включайте **Simulate: ON/OFF**. Во встроенном стартовом примере D0 мигает, переключая N-MOSFET и LED.

Управление: **ПКМ+движение** — вращение камеры, **колёсико** — масштаб, **ЛКМ** — действие выбранного инструмента, `R` — поворот, `Delete` — удаление, `Ctrl+Z` — отмена, `Ctrl+S` / `Ctrl+O` / `Ctrl+N` — сохранить / открыть / создать (когда фокус не в поле кода).

> ⚠️ Встроенный компилятор не поставляется вместе с программой. **Компилируйте только собственный/доверенный код C++**: загруженная DLL исполняется в процессе Electric3D и имеет права вашей учётной записи. Программа не подключается к реальной плате/COM-порту и не прошивает физический микроконтроллер.

## Сборка EXE через GitHub (без Python)

1. Создайте репозиторий `Electric3D-CPP` или используйте старый репозиторий, **заменив** файлы предыдущей Python-версии на файлы из ZIP (старые исходники Python не нужны).
2. Загрузите содержимое ZIP **в корень** GitHub-репозитория, включая скрытую папку `.github`.
3. Вкладка **Actions → Build Electric3D C++ for Windows → Run workflow**. Или дождитесь запуска после `push` в ветку `main` / `master`.
4. Дождитесь успешной сборки, откройте выполненный run, скачайте артефакт **Electric3D-v0.3-Windows-x64**, распакуйте и запустите `Electric3D.exe`.

Локальная сборка в **Developer Command Prompt for VS 2022**:

```powershell
cmake -S . -B build -G "Visual Studio 17 2022" -A x64
cmake --build build --config Release
ctest --test-dir build -C Release --output-on-failure
```

## Проект и формат

```
Electric3D-CPP/
├── .github/workflows/build-windows.yml
├── include/electric3d/core.hpp
├── src/core.cpp              # модели, JSON .elctrd v1-v3
├── src/simulation.cpp        # приблизительная симуляция
├── src/main_win.cpp          # нативный Win32 3D редактор и C++ firmware
├── tests/test_core.cpp       # тесты модели и симуляции
├── examples/                 # .elctrd и примеры программы C++
├── CMakeLists.txt
└── README.md
```

Формат `.elctrd` — JSON UTF-8, `version: 3`, с массивами `parts`, `wires`, `board: {width,height}` и полем `controller_code`. **Это исходный учебный PCB-редактор**, он ещё **не** экспортирует Gerber-файлы для производства реальной печатной платы, не проектирует дорожки по слоям, не моделирует переменный ток, тепло, сложные полупроводниковые ВАХ и электрические ограничения. Для настоящих плат необходимы специализированные EDA и проверка инженером.

## Пример C++ API

```cpp
extern "C" __declspec(dllexport)
void controller_tick(const int* input, int* output, double seconds) {
    output[0] = int(seconds * 2) % 2 == 0; // D0 blinking
    output[1] = input[1];                  // D1 copied
    output[2] = 0;
    output[3] = 0;
}
```

Входы и выходы читаются/записываются в массивы длиной **4** (D0..D3); `seconds` — время симуляции с запуска прошивки. Контроллер активен только если VCC–GND более 3 В. В реальном устройстве нужны уровни логики, сопротивление выводов, ограничения по току и даташиты — в текущей модели все эти моменты упрощены.
